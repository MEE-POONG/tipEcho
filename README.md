# 🎁 TipEcho — ระบบส่งของขวัญและแจ้งเตือนการโดเนทแบบเรียลไทม์

**TipEcho** คือระบบสำหรับรับการสนับสนุน (โดเนท / ส่งของขวัญ) สำหรับสตรีมเมอร์และครีเอเตอร์ โดย **ผู้โดเนทไม่จำเป็นต้องสมัครสมาชิกหรือเข้าสู่ระบบ** สามารถเลือกสินค้า/ของขวัญ ระบุจำนวนชิ้น กรอกชื่อ และพิมพ์ข้อความเพื่อให้แสดงแจ้งเตือนขึ้นหน้าจอไลฟ์สด (OBS Overlay) ได้ทันทีแบบเรียลไทม์

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **หน้าส่งของขวัญสำหรับผู้โดเนท (`/`)**
   - ไม่ต้องสมัครสมาชิกหรือล็อกอิน (Guest Donation)
   - เลือกของขวัญจากรายการสินค้า (มีอิโมจิ ชื่อของขวัญ และราคาต่อชิ้น)
   - เลือกจำนวนของขวัญที่ต้องการส่ง (`×1`, `×3`, `×5`, `×10`, `×20` หรือกำหนดเอง) พร้อมคำนวณยอดโดเนทอัตโนมัติ
   - แสดง **ตัวอย่างการแจ้งเตือนสด (Live Alert Preview)** ขณะพิมพ์ชื่อและข้อความ
   - ระบบจำลองการชำระเงิน (**Mock Payment**) ทั้งแบบกดส่งทันทีในคลิกเดียว และแบบจำลอง QR PromptPay

2. **หน้าแจ้งเตือนสำหรับ OBS Studio (`/overlay`)**
   - แสดงผลครบทั้ง **อิโมจิของขวัญ**, **ชื่อผู้โดเนท**, **ข้อความ**, และ **จำนวนการโดเนท (จำนวนชิ้น + ยอดเงินรวม)**
   - **ระบบคิวแจ้งเตือนอัตโนมัติ (Alert Queue)**: เมื่อมีคนส่งของขวัญเข้ามาพร้อมกันหลายรายการ ระบบจะเข้าคิวและแสดงทีละรายการตามเวลาที่ตั้งไว้
   - พื้นหลังโปร่งใส 100% สำหรับนำไปใส่ใน **OBS Browser Source** (หรือเปิดโหมดจำลองพื้นหลังด้วย `/overlay?preview=1`)
   - เสียงเอฟเฟกต์แจ้งเตือนอัตโนมัติด้วย Web Audio Synthesizer (ไม่ต้องพึ่งไฟล์เสียงภายนอก) และรองรับเสียงอ่านข้อความภาษาไทย (Text-to-Speech)

3. **หน้าจัดการของครีเอเตอร์ (`/dashboard`)**
   - ดูสถิติยอดโดเนทรวม จำนวนของขวัญที่ได้รับ และประวัติการโดเนทแบบเรียลไทม์
   - ปุ่ม **ยิงแจ้งเตือนทดสอบ (Test Alert)**, **ข้ามแจ้งเตือนปัจจุบัน (Skip)**, และ **สั่งแสดงผลซ้ำ (Replay Alert)**
   - จัดการสินค้า/ของขวัญ: เพิ่มของขวัญใหม่ เลือกอิโมจิ ตั้งราคา เลือกสีธีม และเลือกเสียงแจ้งเตือน หรือลบรายการที่ไม่ต้องการ
   - ตั้งค่าชื่อช่อง อิโมจิประจำตัว เป้าหมายการโดเนท (Goal) และระยะเวลาแสดงแจ้งเตือนบนหน้าจอ

---

## 🚀 วิธีเริ่มต้นใช้งาน

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รันเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

เปิดเบราว์เซอร์ไปที่:
- **หน้าส่งของขวัญ (ผู้โดเนท):** `http://localhost:3000/`
- **หน้าแจ้งเตือน OBS Overlay:** `http://localhost:3000/overlay` (หรือ `http://localhost:3000/overlay?preview=1` สำหรับโหมดทดสอบ)
- **หน้าจัดการของครีเอเตอร์:** `http://localhost:3000/dashboard`
